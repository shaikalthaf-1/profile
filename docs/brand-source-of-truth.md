## Brand System Direction

The redesign should be inspired by enterprise cloud products, not by resume templates.

Recommended direction:

- Visual tone: enterprise SaaS, cloud control plane, technical founder.
- UI density: more like Azure Portal, Cloudflare, Vercel, and Stripe product surfaces than a decorative resume site.
- Colors: avoid a one-note blue or purple palette. Use a restrained neutral base with clear cloud/product accents.
- Typography: modern sans-serif with strong hierarchy and compact product UI labels.
- Motion: subtle state changes and scroll transitions only where they clarify structure.
- Icon language: cloud, agent, workflow, shield, network, deployment, governance.
- Evidence visuals: architecture diagrams, workflow maps, product screenshots, terminal snippets, pipeline views.
