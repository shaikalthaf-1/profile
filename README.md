# ALTHAF SHAIK — Enterprise Executive Portfolio

> Senior DevOps & Network Automation Engineer · Enterprise Azure | Terraform | DevOps | Palo Alto Networks | Platform Engineering

This repository contains the complete production-ready enterprise web application for **ALTHAF SHAIK**, built using Microsoft Fluent Design aesthetics, a pure white background system (`#FFFFFF` / `#F8FAFC`), and zero black backgrounds.

---

## 🚀 Key Architectural Highlights

- **Enterprise Design System**: Inspired by Microsoft Azure, HashiCorp, Cloudflare, and GitHub Enterprise (`#0078D4` Azure Blue, `#38BDF8` Sky Accent, Deep Slate `#0F172A`).
- **Primary Career Focus**: Senior DevOps & Network Automation Engineer at **Uniper** *(Client Assignment via Dhakium)*.
- **10 Complete Pages**:
  1. `index.html` — Full Screen Hero, Canvas Network Animation, Statistics Counters, Marquee Tech Slider.
  2. `about.html` — 9 Core Engineering Pillars, Animated Career Timeline, Skills Evolution, Engineering Principles.
  3. `experience.html` — Uniper Exclusive Role Focus, 5 Expandable Responsibility Accordions, Metrics Bar, Enterprise Projects.
  4. `case-studies.html` — Live Search Dashboard, Tech Selector, Category Filters, 15 Modern 3D Cards, Detail Modal Popups.
  5. `azure-network-modernization.html` — 3000+ Word Deep-Dive Case Study, SVG Architecture Diagram, LLD Tables, Terraform HCL Blueprints.
  6. `technologies.html` — Live Search, Category Filters, 12 Animated Cards with Skill Progress Bars & Experience Badges.
  7. `achievements.html` — Animated Counters, 8 Milestone Timeline Entries, 4 Award Cards.
  8. `certifications.html` — Microsoft & IBM Certified Credentials with Verification Buttons.
  9. `resume.html` — Embedded PDF Viewer, Download Buttons, ATS-Structured Text Resume.
  10. `contact.html` — Direct Communication Details, Modern Form Handler, Interactive Location Map SVG.
  11. `404.html` — Custom Microsoft Fluent Light Error Page.
- **Embedded Resume & Avatar**: Integrated vector avatar (`assets/Shaik_Profile.svg`) and PDF resume (`assets/Shaik_Althaf_Resume.pdf`).
- **SEO & PWA Configured**: Complete `sitemap.xml`, `robots.txt`, `manifest.json`, Schema.org JSON-LD, and Open Graph metadata.
