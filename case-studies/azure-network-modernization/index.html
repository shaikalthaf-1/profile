1. Executive Summary & Business Value

Uniper, a global energy supplier managing critical European power generation and gas trading infrastructure, partnered with our cloud architecture team to modernize their multi-subscription Azure network perimeter.

01. Business Challenge

Fragmented VNet peering mesh across 50+ subscriptions, uninspected internet egress bypasses, manual 3-week provisioning delays, and single-point-of-failure firewall VMs.

02. Technical Solution

Architected dual Azure Virtual WAN Hubs (East US and West Europe) with integrated Palo Alto Cloud NGFW NVAs, BGP dynamic routing, and modular Terraform IaC blueprints.

03. Execution & Outcome

Executed zero-downtime cutover across live production energy trading workloads, establishing 100% Zero-Trust traffic inspection and automated Panorama rule sync.

04. Business Value Delivered

Accelerated new environment setup speed by ~40%, achieved 99.99% multi-region availability, and pre-emptively resolved 90% of anomalies via Prometheus & Grafana.

2. Architectural Transformation: Before vs. After

Direct architectural comparison showing operational and security enhancements before and after modernization.

❌ BEFORE (Legacy Architecture)

  • Manual Routing: Complex mesh of 120+ unmonitored VNet peerings with static UDRs.
  • Security Blindspots: Direct uninspected internet egress via public IPs in spoke VNets.
  • Slow Provisioning: 3-week manual ticket approval process for new environment setups.
  • Single Point of Failure: Legacy standalone firewall NVA virtual machines without SLA failover.
  • Uncoordinated Security: Manual firewall policy updates across individual devices.

✅ AFTER (Modernized Zero-Trust Architecture)

  • Virtual WAN Hub Backbone: Centralized managed routing over Azure global high-speed backbone.
  • 100% Zero-Trust Egress: Forced packet inspection via Palo Alto Cloud NGFW NVAs.
  • Automated Terraform IaC: Environment provisioning accelerated by ~40% via modular blueprints.
  • High Availability (99.99% SLA): Dual-region Virtual Hubs with BGP active-active failover.
  • Panorama Centralized Sync: Automated REST API policy deployment across all firewalls.

8. Terraform IaC Blueprint & State Locking

Production HCL code blueprint illustrating custom Virtual Hub route table overrides and Azure Blob state locking.

# Azure Virtual Hub Custom Route Table Override (HCL 2.0)
resource "azurerm_virtual_hub_route_table" "vhub_route_table" {
  name           = "rt-vhub-zero-trust"
  virtual_hub_id = azurerm_virtual_hub.vhub_eastus.id
  labels         = ["production", "zero-trust-egress"]

  route {
    name              = "All-Traffic-To-PaloAlto-NVA"
    destinations_type = "CIDR"
    destinations      = ["0.0.0.0/0", "10.0.0.0/8"]
    next_hop_type     = "ResourceId"
    next_hop          = azurerm_palo_alto_next_generation_firewall.palo_nva.id
  }
}

12. Key Engineering Takeaways

  • Modularize IaC Early: Authoring versioned Terraform modules saved 120+ hours of refactoring during production rollout.
  • Enforce Pre-Commit Policy Gates: Static security scanning via OPA Rego prevented 95% of potential VNet misconfigurations prior to deployment.
  • Validate Failover Continuously: Automated BGP health probes ensure multi-region failovers execute within specified SLAs (<10s).
